
# You've Got Mail

## About

You've Got Mail is my first completed game development project, created using GameMaker LTS. It features an interactive mailbox where players discover personal letters, with progression based on reading each letter.

This project demonstrates my skills in game logic, state management, and 2D pixel art.

## Features

- **Letter Progression:** Letters advance only after being opened and read.
- **Interactive Mailbox:** Open and close the mailbox to access letters.
- **Completion State:** The mailbox is empty once all letters have been read.
- **Original Artwork:** Custom sprites created using Aseprite.

## Play the Game

Download `Youve_Got_Mail_Playable.zip`, extract the files, and run the `.exe` to play. No installation required!

## Technologies & Tools

- **GameMaker LTS** - Game development and logic
- **Aseprite** - Pixel art and sprites
- **Canva** - Background art
